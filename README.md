# Odoo Sales Management Customization

## Overview
An Odoo development project focused on customizing sales management workflows and extending the standard Sales module.

## Features
- Developed a custom Sales Order model with order lines and state management.
- Implemented automatic calculations, validations, and sequence-based numbering.
- Added restrictions on modifying or deleting confirmed orders.
- Integrated Chatter and Activities for order tracking.
- Extended the standard Sales Order with a rejection workflow using a custom wizard.
- Recorded rejection reasons, users, and dates.
- Created custom views, menus, and security groups.
- Developed a QWeb HTML product report displaying product details, prices, and barcodes.

## Technologies
- Python
- Odoo ORM
- XML
- QWeb
- PostgreSQL
